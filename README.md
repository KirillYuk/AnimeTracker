# AnimeTracker Bot

AnimeTracker is a Telegram bot for searching anime and viewing basic information about it.

The project is made for **learning Python, Telegram bots, APIs, and asynchronous programming**.

## ⚠️ Project use

This project is made for **educational and non-commercial use only**.

It is a personal learning project. It uses the **AniList API** to get anime information.

The project does not sell anime data or provide paid services.
